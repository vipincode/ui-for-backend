# Next.js + Tailwind CSS v4 + Shadcn

### File structure

```
src/
├── app/
│   ├── fonts/              ← Local font files (.woff2)
│   ├── globals.css         ← @theme, :root, .dark — single source of truth
│   └── layout.tsx          ← Fonts + ThemeProvider
├── components/
│   ├── form/
│   │   └── form-field.tsx  ← Reusable FormField wrapper
│   ├── icons/
│   │   ├── index.ts        ← All icons re-exported with semantic names
│   │   └── icon.tsx        ← Optional typed Icon wrapper
│   ├── providers/
│   │   └── theme-provider.tsx
│   └── ui/                 ← Shadcn components (generated by CLI)
└── lib/
    └── fonts.ts            ← All next/font definitions
```

### `components.json` — ensure CSS variables are on

```json
{
  "style": "new-york",
  "tailwind": {
    "cssVariables": true
  }
}
```

### he Complete `globals.css`

Here is the full `globals.css` with every token namespace wired in. This is the **single file that drives your entire design system**.

### How the Tokens Map to Utilities

| Token in `@theme inline`               | Tailwind class you use |
| -------------------------------------- | ---------------------- |
| `--radius-lg: var(--radius)`           | `rounded-lg`           |
| `--radius-xl: calc(var(--radius)+4px)` | `rounded-xl`           |
| `--shadow-card: 0 2px 8px …`           | `shadow-card`          |
| `--shadow-brand: 0 0 0 3px …`          | `shadow-brand`         |
| `--background-image-brand: linear-…`   | `bg-brand`             |
| `--background-image-dots: url(…)`      | `bg-dots`              |
| `--background-image-hero: radial-…`    | `bg-hero`              |

### Practical component patterns

```tsx
/* Card with noise texture + shadow */
<div className="rounded-xl shadow-card bg-card bg-noise">…</div>

/* Hero section with radial glow overlay */
<section className="relative bg-background bg-hero min-h-screen">…</section>

/* Branded CTA button glow on focus */
<button className="focus-visible:shadow-brand rounded-lg …">…</button>

/* Skeleton shimmer animation */
<div className="bg-muted bg-shimmer animate-[shimmer_1.5s_infinite] bg-[length:200%_100%]" />

/* Stacked shadows (v4 inset-shadow support) */
<input className="shadow-xs inset-shadow-sm rounded-md border border-input" />

/* Inline gradient one-off (no @theme needed) */
<div className="bg-linear-to-br from-primary/20 to-accent/10 rounded-2xl" />
```
